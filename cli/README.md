# CLI Subsystem

## Overview
This directory contains the command-line driver (`won`) for building, running, testing, and querying WON projects.

- **Current Status**: `PLANNED`
- **Planned Commands**:
  - `won build`: Compile source files into native executables.
  - `won run`: Compile and immediately execute.
  - `won test`: Run unit and integration test suites.
  - `won check`: Validate syntax and types without generating native binaries.
  - `won inspect`: Query symbol types, AST, and module interfaces in JSON format for AI agents.
