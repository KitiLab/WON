# Standard Library (`std`)

## Overview
This directory will house the official WON standard library modules.

- **Current Status**: `PLANNED`
- **Planned Modules**:
  - `core`: Fundamental types, `Option`, `Result`, traits, operators.
  - `io`: Fast buffered I/O, file operations, standard streams.
  - `collections`: High-performance arrays, slices, hash maps, strings.
  - `sync`: Thread primitives, channels, mutexes, atomics.
  - `ffi`: C type interoperability helpers and pointer safety abstractions.
