# C Bindings Subsystem

## Overview
This directory contains official bindings and binding generation utilities for C libraries.

- **Current Status**: `UNDER INVESTIGATION`
- **Initial Targets**:
  - `zlib`: Compression and decompression (Phase 0B target).
  - `sqlite3`: Embedded relational database engine (Phase 1/2 target).
  - `libcurl`: Network client library.
- **Reference**: See [`../docs/interoperability.md`](../docs/interoperability.md).
